# 물잔소리 — 플레이스토어 등록 순서

이 문서 하나만 위에서부터 따라가면 돼요. 복사해서 붙여 넣을 글은 회색 상자에 넣어 뒀어요.

| 항목 | 값 |
|---|---|
| 앱 고유 ID (패키지 이름) | `com.nia.mooljansori` — 첫 업로드 후에는 못 바꿔요 |
| 폰 홈 화면 이름 | 물잔소리 |
| 스토어 제목 | 물잔소리 - 물 마시기 알림 |
| 버전 | 1.0.0 (versionCode 1) |
| 가격 | 무료 |
| 카테고리 | 건강/운동 |
| 개인정보처리방침 | `https://(내 사이트 주소).netlify.app/privacy.html` |

> **개인정보처리방침:** 이 `store` 폴더의 `privacy.html`이 안드로이드 앱용 방침이에요. 맨 아래 문의 문장에 이메일을 직접 적어 두는 걸 추천해요. Netlify 사이트에 올린 뒤 `내 사이트 주소/privacy.html`이 열리는지 확인하고, 그 주소를 Play Console에 넣으세요.

---

## 전체 흐름 (개인 계정 기준)

1. Android Studio에서 .aab 파일 만들기
2. Play Console에서 앱 만들기
3. 앱 콘텐츠(설문) 채우기
4. 스토어 등록정보 채우기
5. **비공개 테스트** 시작 → 테스터 **12명 이상**이 **14일 연속** 참여
6. 프로덕션 액세스 신청 → 승인되면 정식 출시

개인 계정은 5번이 꼭 필요해요. 테스터 12명을 미리 모아 두세요. 테스터는 안드로이드 폰과 구글 계정이 있어야 해요.

## 3. 앱 콘텐츠 (왼쪽 메뉴 → 정책 → 앱 콘텐츠)

| 항목 | 답 |
|---|---|

| 앱 액세스 권한 | **모든 기능을 특별한 액세스 권한 없이 사용할 수 있음** |
| 광고 | **아니요, 광고가 포함되어 있지 않습니다** |
| 콘텐츠 등급 | 아래 표 참고 |
| 타겟층 | **18세 이상**만 선택 (술 기록 기능이 있어서 가장 안전해요) |

| 데이터 보안 | 아래 표 참고 |
| 정부 앱 | 아니요 |
| 금융 기능 | 해당 없음 |
| 건강 앱 | **영양 및 체중 관리** 선택 |
| 광고 ID | **아니요** (광고 ID를 쓰지 않아요) |

### 콘텐츠 등급 설문
- 이메일 입력, 카테고리는 **"기타 모든 앱 유형"**
- 폭력, 성적 내용, 욕설, 도박: **아니요**
- **술·담배·약물 관련 내용: 예** — 사용자가 마신 술의 양을 기록하는 기능이 있어서 솔직하게 "예"로 답해요. (술을 권하거나 판매하지는 않아요)
- 사용자 간 소통·채팅, 위치 공유, 디지털 상품 구매: **아니요**

술 항목 때문에 등급이 전체 이용가보다 조금 올라갈 수 있어요. 거짓으로 답하면 나중에 앱이 내려갈 수 있으니 그대로 답하는 게 맞아요.

### 데이터 보안
| 질문 | 답 |
|---|---|
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **아니요** |

물잔소리는 기록을 폰 안에만 저장하고 어디로도 보내지 않아요. 구글 기준으로 폰 밖으로 나가지 않는 데이터는 "수집"이 아니에요.

### 간단한 설명 (80자 이내)
```
마신 물을 기록하면 물잔이 차올라요. 잊을 때쯤 잠금화면으로 잔소리해 주는 물 마시기 앱
```

### 자세한 설명 (4,000자 이내)
```
"물 좀 마셔!"
하루에 물 몇 잔 마셨는지 기억나세요? 물잔소리는 마신 물을 기록하고, 깜빡할 때쯤 잔소리로 알려 주는 물 마시기 앱이에요.

■ 물잔이 차오르는 기록
컵 버튼을 한 번 누르면 기록 끝. 화면 속 유리잔에 물이 찰랑 차오르고, 목표까지 몇 잔 남았는지 바로 알려 줘요.

■ 내 컵으로 정확하게
머그, 텀블러, 생수병… 컵마다 용량이 다르죠. 내가 쓰는 컵의 이름과 용량을 등록해 두면 버튼 하나로 정확하게 기록돼요.

■ 커피·차는 인정된 만큼만
물 대신 마신 음료는 종류별로 물로 치는 비율이 달라요. 커피 80%, 차 90%처럼 기본값이 들어 있고, 믹스커피·콤부차·탄산수 같은 내 음료도 직접 추가할 수 있어요.

■ 술은 마신 만큼 빼요
술은 수분을 빼앗아요. 술을 기록하면 마신 만큼 오늘 마신 물에서 빠지니까, 그만큼 물을 더 마시면 돼요.

■ 잠금화면 잔소리 알림
1시간마다, 아침 8시부터 밤 10시까지처럼 간격과 시간대를 정해 두면 폰이 잠겨 있어도 알림이 울려요. 앱을 켜 둔 상태에서는 화면 가운데에 반투명 물잔이 살짝 떴다 사라져요.

■ 최근 7일 그래프
요즘 물을 얼마나 마셨는지 일주일 흐름을 한눈에 볼 수 있어요. 목표를 채운 날은 진하게 표시돼요.

■ 가볍고 안전하게
회원가입도 로그인도 없어요. 기록은 내 폰에만 저장되고 어디로도 보내지 않아요. 광고는 화면 아래 작은 배너 하나뿐이에요.

※ 음료별 인정률과 술 계산은 습관을 만들기 위한 참고용이며 의학적 조언이 아니에요.
```

## 5. 비공개 테스트 (왼쪽 메뉴 → 테스트 및 출시 → 테스트 → 비공개 테스트)

1. **트랙 만들기** → 이름은 아무거나 (예: 지인 테스트)
2. **테스터** 탭 → **이메일 목록 만들기** → 테스터 12명 이상의 **구글 계정 이메일**을 넣어요. 여유 있게 15명 정도 넣는 걸 추천해요.
3. **국가/지역**: 대한민국 선택
4. **새 버전 만들기**
   - "Google Play 앱 서명" 안내가 나오면 **계속** (구글이 관리하는 서명을 그대로 써요)
   - 1번에서 받은 **.aab 파일**을 올려요
   - 버전 이름은 자동으로 채워져요. 출시 노트는 `첫 테스트 버전이에요.`
5. **검토 후 출시 시작** → 구글 검토가 끝나면(보통 며칠) 테스트가 열려요.
6. 테스터 탭의 **"웹에서 참여" 링크**를 복사해서 테스터들에게 보내요.
   - 테스터는 링크를 열고 **테스터 되기**를 누른 다음, 플레이스토어에서 설치하면 돼요.
   - **14일 동안 테스트에서 나가면 안 돼요.** 앱을 지우지 말고 가끔 열어 달라고 부탁하세요.

## 6. 정식 출시

1. 비공개 테스트 **14일**이 지나면 대시보드에 **"프로덕션 액세스 신청"** 버튼이 열려요.
2. 테스트가 어땠는지 묻는 질문에 답해요. 예: 지인들이 쓰면서 알려 준 의견(간격이 너무 좁았다 등)과 그래서 고친 점.
3. 승인되면 **프로덕션 → 새 버전 만들기** → 테스트에 올렸던 같은 버전을 그대로 선택해 출시해요.
